# phasekit dependency policy

**Status:** living and normative. A new dependency is named in its plan step, fits a tier below and passes `cargo deny
check` (T5: the site's licence check, PLAN.md M21.1); [deny.toml](../deny.toml) holds the licence allow-list and the
bans. The evidence and rationale are [research/dependencies.md](research/dependencies.md) (frozen, 2026-10-04), whose
§3.1 this replaces: where they differ, this file and [ARCHITECTURE.md](ARCHITECTURE.md) D1 win.

| Tier | Covers | Allowed third-party crates | Rule |
|---|---|---|---|
| T0 core | `phasekit-core` and `phasekit-data`, default build | none: std only until M9 | No proc macros, `build.rs` or `-sys` crates; `gates deps` enforces it |
| T1 opt-in features of core | additive, off by default, never changing numerics (K13), except `libm`, which swaps the transcendental backend (opt-in: ARCHITECTURE.md D12), and `simd` through the `libm` it enables | `rayon` (M9.1), `libm` (M9.3), `fearless_simd` 1.x for the `simd` feature (M12.4; `simd` enables `libm`, user decision SL1; it ships only if M12.7's gate passes, D9); later only behind its trigger: `serde_json` for a `json` feature (once a runtime-JSON consumer is scheduled; until then the serde mirror lives in xtask, S-12) | Permissively licensed and wasm-clean |
| T1f model families | `phasekit-cubic` (M11), `phasekit-mix` (M13), `phasekit-iapws` (M14), `phasekit-humidair` (M18; its parts are `Fluid`s it takes, user decision HA4), later the other family crates; and `phasekit-diagram` (M19), no family but held to the same tree (user decisions WS4, DG3) | none: `phasekit-core`'s public API only, default features off | A family's milestone holds the core unchanged (`gates core-frozen`; D3); `gates deps` enforces the tree |
| T2 facades | `phasekit-capi`, `-wasm`, `-py` | pyo3 (numpy optional), wasm-bindgen (js-sys only if needed), wit-bindgen, uom | Nothing leaks into core; each facade states its own MSRV |
| T3 dev-only | tests, fixtures, benches | num-dual (no default features), proptest (std only), criterion, gungraun (Linux), allocation-counter (user decision AC1), insta or expect-test, cc (`phasekit-capi`'s C smoke test, M10.4), wasm-bindgen-test (`phasekit-wasm`'s tests under Node, M10.8) | Never in a public API; benches live in the unpublished `phasekit-verify` |
| T4 tools | the unpublished xtask and CI binaries | serde, serde_json, syn (`gates complexity`, user decision CX4), thiserror or anyhow, nalgebra or faer (offline); cargo-deny, cargo-semver-checks, cargo-shear, cargo-mutants, cargo-nextest, cbindgen CLI, wasm-bindgen-cli, reuse, cargo-about, wasmtime | Pinned by `Cargo.lock`, checked by cargo-deny, never shipped |
| T5 site | `site/`, the GitHub Pages site (PLAN.md M21; user decisions WS1, WS2) | bundled into the page: svelte 5 and d3's modules (`d3-scale`, `d3-selection`, `d3-zoom`; M21.2), and three.js (`three` 0.186.1, MIT) for M26's surfaces in WebGL (user decision DG7; pinned at M26.2, its `OrbitControls` from its `addons`); to build and test it: vite, `@sveltejs/vite-plugin-svelte`, typescript, svelte-check, prettier with `prettier-plugin-svelte`, vitest (4.1: StrykerJS 10's runner predates Vitest 5 and runs no test under it, measured at M21.7), `@playwright/test`, `@types/node`, the d3 modules' `@types/…` and `@types/three`, `@stryker-mutator/core` and `@stryker-mutator/vitest-runner` (M21.7); GitHub's `upload-pages-artifact` and `deploy-pages` actions | Pinned by `site/package-lock.json`, the actions by commit; what the page bundles is under a licence `deny.toml` allows, checked and credited by `scripts/site/notices.mjs`; nothing reaches a crate or the npm package |
| Banned | — | `bincode`, `serde_cbor`; `once_cell` and `lazy_static` as direct dependencies; C-linking or `-sys` crates in T0-T1; nightly-only crates or features in published crates; GPL, LGPL and AGPL anywhere; MPL-2.0 in T0-T1 | `deny.toml` |

A dependency that needs a newer Rust than the workspace's `rust-version` (root `Cargo.toml`) waits, or the MSRV is
raised by a user decision (MS1).
