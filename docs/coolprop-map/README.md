# docs/coolprop-map: frozen evidence

**A map of CoolProp v8.0.0 (`reference/CoolProp`, ae81610e), written for the design stage. Not guidance.** It records what
CoolProp does and what is wrong with it; its "port recommendation" sections were inputs to decisions that sometimes
went the other way. Where it disagrees with [ARCHITECTURE.md](../ARCHITECTURE.md) or [DECISIONS.md](../DECISIONS.md),
those win. Open a file only to resolve a citation ("map NN §X", "map NN R5" and other item ids), and read only that
section.
