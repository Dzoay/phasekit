## Scope check (over-engineering)

v0.1 work traces to a requirement, an ARCHITECTURE decision or a user decision almost everywhere: the Tier A shim with
v8.0.0 quirks (9a, 9b), the `libm` hash (12), point-major batches (11), seams-not-implementations for materials,
Gibbs families and SIMD (M5.10 seam tests, M12 behind a gate). Only weekly `cargo-mutants` (X-21) has no owner. The
costliest "reference only" item is the M1.8 C++ build (D15 asks for it; X-08 makes it safe). No post-0.1 family leaks
