# docs/history: frozen design records

**Frozen. Never edited.** These files record how the architecture was chosen on 2026-10-04/05: the inputs digest,
four proposals, the judges, the critiques, the decision log, the plan reviews, and the compiled type sketch that
seeded the workspace at M0.2. They use the old placeholder names `cprs-*`/`cp_*` on purpose, and the paths inside them
are as they were then (`docs/design/` is now `docs/history/`, `docs/design/04-user-decisions.md` is now
[docs/DECISIONS.md](../DECISIONS.md)).

They are not guidance. Where they disagree with [ARCHITECTURE.md](../ARCHITECTURE.md) or [DECISIONS.md](../DECISIONS.md),
those win. Open a file here only to resolve a citation: the S-## and E## ids in the living docs and code are critic
issues in [03-decision-log.md](03-decision-log.md).
